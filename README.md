# GNRS
Single-binary PPG classroom dashboard - Go + SQLite, embedded React/TypeScript SPA. Multi-role auth (admin/pengurus/guru/ortu/murid), kelas + multi-guru + monthly rencana ajar, sesi with start-stop + multi-source materi (kurikulum + Qur'an/Hadits/Tilawati/Doa), Qur'an mushaf reader +   manqul, bacaan tracker, hierarchical pencapaian, mobile-first.
